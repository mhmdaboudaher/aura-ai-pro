# 🚀 AURA AI PRO - Enterprise AI Assistant Platform

AURA AI PRO is a modern, high-performance AI Assistant Web Application built with **Next.js 14**, **Groq API** (`openai/gpt-oss-120b`), and **Tailwind CSS**. Designed for ultra-fast response times, seamless streaming, and an intuitive user interface.

---

## ✨ Features

- **⚡ Lightning-Fast Responses:** Powered by Groq LPU Hardware Acceleration.
- **💬 Smart Context Truncation:** Built-in history management to prevent API rate/token limits.
- **🎨 Modern UI/UX:** Responsive, dark-themed interface built with Tailwind CSS.
- **📝 Full Markdown & Code Highlighting:** Displays code snippets, math formulas, and tables cleanly.
- **🛡️ Error Resilience:** Graceful handling of edge-cases and payload limits.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **AI Engine:** Groq SDK (`openai/gpt-oss-120b`)
- **Deployment:** Vercel / Render
